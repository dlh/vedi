# Security

Only the latest release is supported. Fixes ship as a new release.

Report vulnerabilities privately through [GitHub security
advisories](https://github.com/dlh/vedi/security/advisories/new), not
as issues or pull requests. Include the version (`vedi -v`), how to
reproduce, and what it lets an attacker do.

You will hear back within a week. Please keep the report private until
a fix is released.

Verify a downloaded release against its `checksums.txt`.
