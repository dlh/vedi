h replaces the text with the key bindings and their meaning, laid
out as less lays out its help: a title, a note on the modifier
glyphs, the keys that show help, quit and toggle wrap, then sections
with their names centered in capitals between rules. Each row is the
keys bound to an action, two spaces apart, and what they do beside.
The key column is as wide as the widest list, up to half the room;
a list or a doc too wide for its column continues on the next line.
The status line says how to get back. Any key but a motion or a
search key returns to the text and does nothing else, so q returns
rather than quits and the cursor is where it was.

                            SUMMARY OF VEDI COMMANDS

      ⌃ ⌥ ⌘ are Ctrl, Alt and Cmd: ⌃F is Ctrl+f in the config file.

  h                                       Show the key bindings.
  q                                       Quit.
  w                                       Toggle wrap / nowrap.
  R                                       Reload the file.
 ------------------------------------------------------------------------------

                                     MOVING

  Up  Down  Left  Right  Home  End  j  k  Move the cursor.
  PgDn  Space  f  ⌃F  ⌃V                  Down a page.
  PgUp  b  ⌃B  ⌥V                         Up a page.
  d  ⌃D                                   Down half a page.
  u  ⌃U                                   Up half a page.
  ⌃Left  ⌃Right  ⌥Left  ⌥Right  ⌥B  ⌥F    Move by word.
  g  G  <  >                              First line, last line.
  :                                       Command prompt; N goes to line N.
 ------------------------------------------------------------------------------

                                   SELECTING

  J  K  Shift+Up  Shift+Down  Shift+Left  Extend the selection.
  Shift+Right  Shift+Home  Shift+End
  Shift+PgUp  Shift+PgDn                  Extend by a page.
  ⌃Shift+Left  ⌃Shift+Right  ⌥Shift+Left  Extend by word.
  ⌥Shift+Right
  ⌃A                                      Select all.
  Esc                                     Clear the selection, then the search
                                          highlight.
 ------------------------------------------------------------------------------

                                     MOUSE

  Click, drag                             Move the cursor, select; with Shift,
                                          extend; held at an edge, scroll.
  Double-, triple-click                   Select the word, the line.
  Wheel                                   Scroll; with Shift, sideways.
 ------------------------------------------------------------------------------

                                    COPYING

  ⌃C  y                                   Copy the selection as plain text.
  Enter                                   Copy the selection and quit; with
                                          none, down a line.
 ------------------------------------------------------------------------------

                                   SEARCHING

  /                                       Search; ignores case if lowercase;
                                          empty repeats.
  ?                                       Search backward.
  n  N                                    Next and previous match; ? swaps them.
 ------------------------------------------------------------------------------

                                    PROMPTS

  Up  Down                                Recall earlier searches, or commands.
  Tab                                     Complete; again, the next match.
  Esc  ⌃G  ⌃C                             Cancel.
help  motion scrolls, / searches, any other key returns
