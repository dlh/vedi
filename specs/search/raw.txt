With view_style raw, search reads an escape sequence as text: a
pattern finds part of one, and does not match across one. The input
here holds the raw SGR sequence ESC [ 31 m inside the word red.

-- size --
40x3
-- config --
view_style raw
-- input --
re[31md 31m
-- keys --
/ "31m" Enter
-- screen --
re[^[][{{31m}}d {31m}

-- keys --
/ "red" Enter
-- screen --
re[^[][31md 31m
