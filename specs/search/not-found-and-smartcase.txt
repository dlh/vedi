A pattern with no match leaves the cursor and says so, naming the
pattern searched for, not what was last typed at the prompt. Matching
is smartcase: a lowercase pattern ignores case, one with an uppercase
letter does not.

-- input --
Foo
foo
-- keys --
/ "FOO" Enter
-- screen --
Foo
foo



not found: FOO                    ? help
-- cursor --
0 0
-- keys --
/ "zzz" Esc n
-- screen --
Foo
foo



not found: FOO                    ? help
-- keys --
/ "foo" Enter n
-- screen --
[Foo]
[foo]



<stdin>  line 2/2  wrap           ? help
-- cursor --
1 0
