While a search is highlighted, s labels each match shown, over its
first cells, and typing a label puts the cursor on that match. With
the highlight cleared, it labels the lines again.

-- input --
top
foo bar foo
baz
a foo
-- keys --
"/foo" Enter s
-- screen --
top
<1>{{oo}} bar <2>{oo}
baz
a <3>{oo}

<stdin>  line 2/4  /foo  1/3  wrap
-- keys --
2
-- screen --
top
{foo} bar {{foo}}
baz
a {foo}

<stdin>  line 2/4  /foo  2/3  wrap
-- cursor --
1 8
-- keys --
Esc s
-- screen --
<1>op
<2>oo bar foo
<3>az
<4> foo

-- keys --
4
