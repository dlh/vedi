/ opens a prompt on the status line; Backspace edits it and Enter
searches from the cursor. Every match is highlighted and the cursor goes
to the first one. n and N go to the next and previous match, wrapping
around the buffer with a note. Shift+movement selects from a match. Esc
clears the selection first and the highlight second.

-- input --
foo
bar foo
foo
-- keys --
/ "fox"
-- screen --
foo
bar foo
foo


/fox
-- keys --
Backspace "o" Enter
-- screen --
[foo]
bar [foo]
[foo]


<stdin>  line 1/3  wrap           ? help

-- keys --

-- keys --
n n
-- screen --
[foo]
bar [foo]
[foo]
