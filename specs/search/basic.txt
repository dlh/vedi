/ opens a prompt on the status line; Backspace edits it and Enter
searches from the cursor. Every match is highlighted and the cursor goes
to the first one. n and N go to the next and previous match, wrapping
around the buffer with a note. Shift+movement selects from a match, and
selected cells show as selected. Esc clears the selection first and the
highlight second.

-- input --
foo
bar foo
foo
-- keys --
/ "fox"
-- screen --
foo
bar foo
foo


/fox
-- keys --
Backspace "o" Enter
-- screen --
{foo}
bar {foo}
{foo}


<stdin>  line 1/3  wrap           h help
-- cursor --
0 0
-- keys --
n
-- cursor --
1 4
-- keys --
n n
-- screen --
{foo}
bar {foo}
{foo}


search wrapped                    h help
-- cursor --
0 0
-- keys --
N
-- screen --
{foo}
bar {foo}
{foo}


search wrapped                    h help

Shift+Right Shift+Right y
