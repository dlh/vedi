The status line starts with the name of the input the cursor's line
came from: the file as given, or <stdin> for standard input, whether
that is the only input or a "-" among the files. With several, the
input's number follows the name, and lines are counted within it.

-- size --
28x3
-- args --
--no-file-separators a.txt - b.txt
-- input --
abc
-- next-file --
-- input --
def
-- next-file --
-- input --
ghi
-- eof --
-- screen --
abc
def
a.txt 1/3  line 1/1  wrap
-- keys --
Down
-- screen --
abc
def
<stdin> 2/3  line 1/1  wrap
-- keys --
Down
-- screen --
def
ghi
b.txt 3/3  line 1/1  wrap
