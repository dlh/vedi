Each input's lines are numbered from 1, as the status line counts
them. The row naming an input has no number and starts where the text
does.

-- size --
28x7
-- args --
a.txt b.txt
-- config --
line_numbers yes
-- input --
a1
a2
-- next-file --
-- input --
b1

1 a1
2 a2

1 b1
  ~
