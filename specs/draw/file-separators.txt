With several inputs a row names each one, above its first line: two
dashes, the name as given, and dashes to the edge. It is not a line:
the cursor never rests on it and no line is numbered for it. The
view starts at the first input's row. Scrolling counts the rows, the
wheel too.

-- size --
28x5
-- args --
a.txt - b.txt
-- input --

a2

-- input --
s1
