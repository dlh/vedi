A name too long for the status line keeps its first directory and its
end, with … for the directories left out between them: vedi/…/status.rs.
The input's number, the line counter and the mode are never cut. When
even that is too long, the file name stands alone, and clips at the edge
as it always has, as the separator row above the file does.
