A key with no binding says so on the status line; the next key clears
it. A key that came with text is named as the key.

-- input --
abc
-- keys --
z
-- screen --
abc
~
~
~
~
<stdin>  line 1/1  wrap  [not bound: z]
-- keys --
Right
-- screen --
abc
~
~
~
~
<stdin>  line 1/1  wrap           h help
-- keys --
Alt+x:"≈"
-- screen --
abc
~
~
~
~
[not bound: Alt+x]                  h help
