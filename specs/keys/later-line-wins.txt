When a key is mapped twice the later line wins.

-- config --
map x quit
map x help
-- size --
60x6
-- input --
abc
-- keys --
x
-- screen --
                            SUMMARY OF VEDI COMMANDS

      ⌃ ⌥ ⌘ are Ctrl, Alt and Cmd: ⌃F is Ctrl+f in the confi

  h  x                                    Show the key bindi
help  motion scrolls, / searches, any other key returns
