map KEY cycle SETTING binds a key to cycling the setting. Here Alt+w
turns the edge markers on, then off, reporting each on the status
line; the help screen lists the key on the setting's row.

-- config --
map Alt+w cycle edge_markers

                            SUMMARY OF VEDI COMMANDS

      ⌃ ⌥ ⌘ are Ctrl, Alt and Cmd: ⌃F is Ctrl+f in the config file.

  h                                       Show the key bindings.
