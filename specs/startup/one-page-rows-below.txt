one_page_rows_below is the rows -F leaves below the text, 1 unless
set, for a prompt taller than one row: at 2, three lines do not fit a
four-row screen, so the pager stays.

-- size --
40x4
-- args --
-F
-- config --
one_page_rows_below 2
-- input --
line 1
line 2
line 3
-- screen --
line 1
line 2
line 3
<stdin>  line 1/3  wrap           h help
