view_style color, plain or raw at the : prompt changes how the text's
styling is shown, for the rest of the run; cycle view_style steps
through them. The status line shows plain or raw.

-- size --
46x3
-- input --
line 1
-- keys --
: "view_style plain" Enter
-- screen --
line 1

<stdin>  line 1/1  wrap  plain          h help
-- keys --
: "view_style color" Enter
-- screen --
line 1

<stdin>  line 1/1  wrap                 h help
-- keys --
: "cycle view_style" Enter : "cycle view_style" Enter
-- screen --
line 1

<stdin>  line 1/1  wrap  raw            h help
-- keys --
: "cycle view_style" Enter
-- screen --
line 1

<stdin>  line 1/1  wrap                 h help
-- keys --
: "view_style bright" Enter
-- screen --
line 1

view_style takes color, plain or raw    h help
