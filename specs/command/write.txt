write and a file name saves the text to that file as the view shows
it, and says how many lines went: with view_style color, each run's
style as SGR and its link as OSC 8, a color carried in from an
earlier line included; with plain, the text and its links; with raw,
the input as it came. With a selection, write saves that alone. A
file that exists is refused: write! overwrites it. The name is the
rest of the line, spaces included. The input here holds the raw SGR
sequences ESC [ 31 m and ESC [ 0 m.

-- args --
f.txt
-- input --
[31mred
two[0m

-- keys --
: "write out.txt" Enter
-- screen --
red
two



wrote 2 lines to out.txt          h help
-- written out.txt --
[0;31mred
two[0m

-- keys --
: "write out.txt" Enter
-- screen --
red
two



out.txt exists; write! overwrites
-- keys --
: "write f.txt" Enter
-- screen --
red
two



f.txt exists; write! overwrites   h help
-- keys --
: "write! out.txt" Enter
-- screen --
red
