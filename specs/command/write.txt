write and a file name saves the text to that file as copy sends it,
and says how many lines went: plain, its colors and links dropped,
under view_style color and plain alike; with raw, the input as it
came. With a selection, write saves that alone, a selected last
newline included. A flag before the name saves something else: --raw
the input itself, byte for byte, a selection's lines whole, since a
cut through an escape means nothing, one it ends at the start of left
out; --color what the screen shows, encoded afresh, one SGR per
change of style and links as OSC 8, the color a selection starts in
written first so an excerpt stands on its own. Under view_style raw
the escapes are text, and --color writes them as text, as plain does.
Tab after write offers the flags. A file
that exists is refused: write! overwrites it. The name is the rest of
the line, spaces included; a leading ~ is the home directory, the
status line keeping the name as typed. The input here holds the raw
SGR sequences ESC [ 31 m and ESC [ 0 m.
