tab_width N at the : prompt sets the cells per tab stop for the rest
of the run. The cursor keeps its place in the text. N is 1 to 65535,
a row's most cells; wider would overflow the layout. This file holds
a raw tab.

-- keys --
Right : "tab_width 4" Enter
