clipboard_cmd is not a : command: a line could set it to any command,
which the next copy would run. The config and --clipboard-cmd set it.

-- size --
40x5
-- input --
hello
-- keys --
: "clipboard_cmd sh -c false" Enter
-- screen --
hello
