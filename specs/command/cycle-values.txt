cycle SETTING V1 V2… sets the setting to the value after its current
one in the list, the first when the current is not in it: tab_width
8 4 takes the default 8 cells to 4, then 8, then 4 again. Any setting
the prompt takes may be given values, two or more and none twice,
each checked as the setting checks it; a key may be bound to the
same, and the help screen names its values. A setting without fixed
values needs them; open_cmd takes none. This file holds a raw tab.

                            SUMMARY OF VEDI COMMANDS

      ⌃ ⌥ ⌘ are Ctrl, Alt and Cmd: ⌃F is Ctrl+f in the config file.

  h                                       Show the key bindings.
  q                                       Quit.
  w                                       Toggle wrap / nowrap.
  R                                       Reload the file.
  O                                       Toggle reading through open_cmd.
  T                                       Cycle tab_width: 2, 4.
help  motion scrolls, / searches, any other key returns
