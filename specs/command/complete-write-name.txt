Tab after write, or its flag, completes a file name: the names in the
directory typed so far, the current one with none, that begin as the
last part does. A directory is filled in with a / and no space, so Tab
again goes into it. A name beginning with a dot comes only after one;
a leading ~ is the home directory, kept as typed. The name is the rest
of the line, so one with a space completes whole. A first word
beginning with - is a flag, as write.txt shows, so a name here that
begins with one is filled in after ./; after a flag, as it is.
