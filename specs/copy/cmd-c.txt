                            SUMMARY OF VEDI COMMANDS

      ⌃ ⌥ ⌘ are Ctrl, Alt and Cmd: ⌃F is Ctrl+f in the config file.

  h                                       Show the key bindings.
  q                                       Quit.
  w                                       Toggle wrap / nowrap.
  W                                       Wrap at 80 cells / the screen's edge.
  R                                       Reload the file.
  O                                       Toggle reading through open_cmd.
 ------------------------------------------------------------------------------

                                     MOVING

  Up  Down  Left  Right  Home  End  j  k  Move the cursor.
  0  $  Enter  ⌘Left  ⌘Right
  PgDn  Space  f  ⌃F  ⌃V                  Down a page.
  PgUp  b  ⌃B  ⌥V                         Up a page.
  d  ⌃D                                   Down half a page.
  u  ⌃U                                   Up half a page.
  ⌃Left  ⌃Right  ⌥Left  ⌥Right  ⌥B  ⌥F    Move by word.
  g  G  <  >  ⌃Home  ⌃End  ⌘Up  ⌘Down     Start, end of the text.
  T  M  B                                 Top, middle, bottom of the shown text.
  [  ]                                    Previous, next input or title.
  :                                       Command prompt; N goes to line N.
 ------------------------------------------------------------------------------

                                   SELECTING

  J  K  Shift+Up  Shift+Down  Shift+Left  Extend the selection.
  Shift+Right  Shift+Home  Shift+End
  ⌃Shift+Home  ⌃Shift+End  ⌘Shift+Left
  ⌘Shift+Right  ⌘Shift+Up  ⌘Shift+Down
  Shift+PgUp  Shift+PgDn                  Extend by a page.
  ⌃Shift+Left  ⌃Shift+Right  ⌥Shift+Left  Extend by word.
  ⌥Shift+Right
  ⌃A  ⌘A                                  Select all.
  Esc                                     Clear the selection, then the search
                                          highlight.
 ------------------------------------------------------------------------------

                                     MOUSE

  Click, drag                             Move the cursor, select; with Shift,
                                          extend; held at an edge, scroll.
  Double-, triple-click                   Select the word, the line.
  Wheel                                   Scroll; with Shift, sideways.
 ------------------------------------------------------------------------------

                                    COPYING

  ⌃C  ⌘C  y                               Copy the selection as plain text.
 ------------------------------------------------------------------------------

                                   SEARCHING

  /                                       Search as typed; ignores case if
                                          lowercase; empty repeats.
  ?                                       Search backward.
  n  N  ⌘G  ⌘Shift+G                      Next and previous match; ? swaps them.
  &                                       Filter: list the lines that match;
                                          Enter goes to one.
 ------------------------------------------------------------------------------

                                    PROMPTS

  Up  Down                                Recall earlier lines at this prompt.
  ⌃N  ⌃P  PgDn  PgUp                      Move the pointer at the & prompt.
  Left  Right  Home  End  ⌘Left  ⌘Right   Move in the line.
  ⌃Left  ⌃Right  ⌥Left  ⌥Right  ⌥B  ⌥F    Move by word.
  ⌥Backspace  ⌃Backspace  ⌃W              Delete the word before the cursor.
  ⌘Backspace  ⌃U                          Delete to the start of the line.
  Tab                                     Complete; again, the next match.
  Esc  ⌃G  ⌃C                             Cancel.
help  motion scrolls, / searches, any other key returns
