With the status line hidden, dragging onto the bottom row scrolls a
row per tick, as the status row does. The cursor is drawn again at the
release.

-- size --
20x3
-- config --
status_line no
-- input --
one
two
three
four
five
-- mouse --
press 1 0
move 2 0
-- screen --
one
[two ]
[t]hree
-- cursor --
hidden
-- mouse --
tick
-- screen --
[two ]
[three ]
[f]our
-- cursor --
hidden
-- mouse --
release 2 0
-- cursor --
2 1
