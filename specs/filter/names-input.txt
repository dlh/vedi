With several inputs the list has a separator row before each input's
first listed line, [ and ] go between them, and the status line names
the listed line's input.

-- size --
40x8
-- args --
a.txt b.txt c.txt
-- input --
x1
y
x2
-- next-file --
-- input --
y
-- next-file --
-- input --
x3
-- keys --
& "x" Enter

{x}2
