A separator row counts as a row of the page PgDn and PgUp move the
pointer by, so no listed line is paged over unseen.

20x4
-- args --
a.txt b.txt c.txt d.txt

x1

-- input --
x2
-- next-file --
-- input --
x3
-- next-file --
-- input --
x4
