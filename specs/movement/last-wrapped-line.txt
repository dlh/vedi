G goes to the last row of a wrapped last line, so the end of the text
is on screen; +G follows to that row as input arrives. From the
newline row a full last row opens, G goes back to the row itself.

-- size --
10x5
-- args --
+G
-- input --
line 1
line 2
-- cursor --
1 0

klmnopqrst
uvwxyz0123
