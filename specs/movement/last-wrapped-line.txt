G goes to the end of the text, so the end of a last line that wraps is
on screen, and +G keeps it there as input arrives. A full last row
opens a newline row for the cursor, as End does.

-- size --
10x5
-- args --
+G
-- input --
line 1
line 2
-- input --
abcdefghijklmnopqrstuvwxyz0123
-- screen --
abcdefghij
klmnopqrst
uvwxyz0123

<stdin>  l
-- cursor --
3 0
-- eof --
-- keys --
g G
-- screen --
abcdefghij
klmnopqrst
uvwxyz0123

<stdin>  l
-- cursor --
3 0
-- keys --
Home End
-- cursor --
3 0
