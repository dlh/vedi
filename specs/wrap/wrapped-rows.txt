In wrap mode a long line takes as many rows as it needs, and Down moves
through those rows before reaching the next line. The 4-column screen
truncates the status line.

-- size --
4x5
-- input --
abcdefghij
k
-- screen --
abcd
efgh
ij
k

-- keys --
Down
-- cursor --

-- keys --
