w toggles between wrap and nowrap; the status line shows the mode. The
cursor keeps its position in the text, so End in nowrap then w puts it
on the last wrapped row.

-- size --
26x5
-- input --
abcdefghijklmnopqrstuvwxyz0123
-- screen --
abcdefghijklmnopqrstuvwxyz
0123


<stdin>  line 1/1  wrap
-- keys --
w
-- screen --
abcdefghijklmnopqrstuvwxyz



<stdin>  line 1/1  nowrap
-- keys --
End w
-- screen --
abcdefghijklmnopqrstuvwxyz
0123


<stdin>  line 1/1  wrap
-- cursor --
1 4
