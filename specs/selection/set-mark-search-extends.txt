With the mark set, a search extends the selection to the match, as
in vim's visual mode; without it a search clears the selection.

-- config --
map v set_mark
-- input --
foo
bar foo
-- keys --
Right v / "foo" Enter
-- screen --
{f[}oo ]
[bar ]{foo}
