An input's last newline ends a row like any other: after it comes the
end row, empty, where the cursor rests past the text, as it rests on
the next line's start past any other newline. Down from the last line
goes there, Up comes back to the line's start, Home and End stay; the
row is no line: the status says 2+1/2, the count wc gives. Selected, the
newline shows as a cell and a copy that reaches it ends with it. An
input without one has no end row: see shift-down-on-last-line.
