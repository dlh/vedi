Shift+Down on the last row has no row below to go to, so it extends the
selection to the end of the line. A file that does not end in a newline
copies without one.

-- size --
40x5
-- input --
hello world
second
-- keys --
Down Shift+Down y
-- screen --
hello world
[second]


<stdin>  line 2/2  wrap  [copied 6 chars]
-- cursor --
1 6
-- clipboard --
second
