With the mark set, a row motion with no row left to take goes to the
end of the text downward and to its start upward, as it does with
Shift. So does Enter's move down, with nothing selected yet.

-- size --
40x5
-- config --
map v set_mark
-- input --
one
two
-- keys --
Down v Down y
-- screen --
one
[two]


copied 1 line                     h help
-- cursor --
1 3
-- clipboard --
two
-- keys --
Esc g Right v Up y
-- screen --
[o]ne
two


copied 1 line                     h help
-- cursor --
0 0
-- clipboard --
o
-- keys --
Esc Down v Enter
-- screen --
one
[two]


<stdin>  line 2/2  wrap           h help
-- cursor --
1 3
-- keys --
Enter
-- quit --
-- clipboard --
two
