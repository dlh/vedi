# Contributing

Bug reports and suggestions are welcome as
[issues](https://github.com/dlh/vedi/issues). Pull requests are not accepted
while the project is in an early state.

In a bug report, include:

- the version (`vedi -v`)
- your terminal and OS
- the command you ran
- what you expected and what happened
- input that reproduces it, if you can share it

Report security issues as described in [SECURITY.md](SECURITY.md).
